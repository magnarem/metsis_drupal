# Installation

Place this module in `modules/custom` in the Drupal installation.

## Dependencies,
### Drupal contrib modules

This module requires the following dependencies:

- `drupal/search_api`
- `drupal/search_api_solr`
- `drupal/search_api_autocomplete`
- `drupal/facets`

Install them using:

```bash
composer require drupal/search_api drupal/search_api_solr drupal/search_api_autocomplete drupal/facets
```

See `composer.json` and `metsis_drupal.info.yml` for an updated list of dependencies and versions.
